# Проверка локальной реализации

Дата: 28 сентября 2026 года. Окружение: Windows, Docker Desktop с Linux engine, PowerShell, браузер Codex.

## Выполнено

- Полный `scripts/start.ps1`: сборка PHP-образа, Composer install из lock-файла, миграции PostgreSQL, npm ci и production-сборка Vue внутри Node-контейнера, запуск app/web/db, HTTP 200 для `/up` и `/login`.
- Повторный запуск сохранил базу, изображения и аккаунты. После пересоздания app скрипт перезапускает Nginx для обновления адреса PHP upstream.
- `composer validate --strict`, PHP lint модулей и Pint; `vue-tsc --noEmit`, Prettier, Vite build. Миграции применены, PostgreSQL healthy, веб-порт доступен на 127.0.0.1:8080.
- Вход и выход двух отдельных аккаунтов — автора и преподавателя; доступ к общему пространству.
- В браузере: загрузка PNG, выбор карточки, создание подборки, создание практики, выбор подборки в редакторе, вставка карточки, подпись, копирование в другую ячейку, изменение длины строки, сохранение и повторное открытие.
- Сохранение строки и вставка её в другой блок; создание шаблона практики; открытие готового листа с изображениями и подписями.
- Два окна редактора: первая версия сохранилась, второе окно получило конфликт, загрузка актуальной версии показала правку первого окна.
- Мобильный экран 390 × 844: управление практикой, горизонтальная прокрутка длинной строки, панель выбора асан. Для готового листа предусмотрена отдельная горизонтальная прокрутка, чтобы подписи оставались читаемыми.
- Одноразовые серверные операции в откатываемой транзакции: CAS/409, архив, восстановление UUID при undo, независимые копии, недоступность чужих структурных ID и снимков, изоляция workspace, неизменность снимка после изменения названия/изображения каталога. Пользовательские данные этими операциями не изменялись.

Автоматические тесты, тестовые файлы и тестовые фреймворки не создавались. `pint --test` означает только проверку форматирования PHP.

## Данные после проверки

При первоначальной проверке загрузки использовался предоставленный скриншот целого листа с явным названием «Образец листа — проверка загрузки». Эта карточка, подборка, проверочная практика, строка и шаблон перенесены в архив. Файлы сохранены.

По последующему запросу владельца из первого скриншота вырезан и импортирован 71 отдельный рисунок. Исходник, координаты, карточки и манифест находятся в `resources/imports/reference-sheet`. У 34 миниатюр недостаточно деталей для уверенного определения формы, поэтому названия содержат «уточнить»; их можно редактировать в библиотеке.

Оставлена пустая «Моя первая практика»: пять блоков, одна строка и шесть ячеек в каждом. Два аккаунта созданы без известных паролей по умолчанию; данные входа находятся только в локальном игнорируемом `.runtime/local-access.txt`.
