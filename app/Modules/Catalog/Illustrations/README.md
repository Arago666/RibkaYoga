# Проверенные представления асан

Provider: `App\Modules\Catalog\Illustrations\IllustrationServiceProvider`. Страница `/illustration-settings` позволяет сохранить личное предпочтение, увидеть фактическое покрытие и вращать настоящий параметрический манекен. Миграция `000023` добавляет предпочтения, неизменяемые варианты и nullable-настройки будущих вставок практики; rollback не удаляет данные.

Набор находится в `resources/imports/illustration-styles/poses.json`: четыре вручную сверенные версии — Тадасана, Врикшасана с руками над головой, Вирабхадрасана 2 с согнутым правым коленом, Шавасана с разведёнными руками/ногами. Соответствие связано с SHA-256 исходного PNG, а не названием. Копия того же изображения в новом workspace сохраняет соответствие. Изменившийся рисунок не получает альтернативу по одному лишь имени.

Манекен — собственные трёхмерные координаты суставов, цилиндры и эллипсоиды, освещение и ортографическая камера. Клиентский Canvas отображает проекцию вращаемой геометрии; PHP GD строит неизменяемый PNG 1024×1024 из той же геометрии. Исходные PNG не применяются как текстура или фильтр. Женский/мужской варианты меняют пропорции плеч/таза/конечностей, сохраняя позу; нейтральный вариант также доступен. Стили ограничены действительным проверенным покрытием, для остальных изображений явный исходный fallback.

## Публичный контракт Catalog

- `IllustrationStyles::state()` — предпочтение, покрытие и четыре проверенных карточки/рецепты текущего пространства. Полные исходники пользовательских рисунков не попадают в ответ.
- `preferred()` — личная начальная настройка. Новый документ фиксирует её; существующий `illustration_style=null` означает original.
- `savePreference(style, character, expectedRevision)` — CAS личной настройки.
- `prepare(asanaId, sourceAssetId, style, character)` — явное создание/повторная выдача альтернативы для конкретного текущего рисунка. Возвращает immutable image asset, variant_id, проверенный `ribka-mannequin` render_source и native `ribka-drawing` для линейного стиля. Новое медиа создаётся через публичный Media AssetStore в той же транзакции, исходная карточка не меняется.
- `resolve(asanaId, sourceAssetId, variantId)` — проверяет явный выбор нового снимка; null означает исходную картинку.
- `prepareForSnapshot(asanaId, imageAssetId, style, character)` — позволяет менять только конкретную текущую картинку или ранее проверенный вариант с тем же текущим source asset. Исторический снимок по совпадению asana_id не подменяется.

Стили: original, line, volume. Персонажи: neutral, female, male. Ракурс сохраняемого PNG задан проверенным рецептом, вращение в интерфейсе служит осмотру модели.

## Цепочка вставки и применения

`IllustrationSettings.vue` принимает asanaId/sourceAssetId/imageUrl, выдаёт select(PreparedIllustration) и reset при смене выбора. AsanaPreview добавляет выбранный вариант через query insert_variant; CellPicker имеет отдельный доступный режим выбора стиля. `Asana.illustration_variant_id?: string|null` отличает явный original от отсутствующего override.

`PracticeEditor::resolveCards(ids, variantMap, illustration)` использует явные варианты или настройку конкретного документа. Endpoint `/api/editor/cards/resolve` принимает `illustration_variants: [{asana_id, variant_id:null|uuid}]` и `illustration: {style, character}`. Старый клиент без новых полей вставляет original; уже сохранённые снимки никогда не изменяются от предпочтения.

Практика меняет ранее вставленные изображения только через `PracticeIllustrations`: предпросмотр exact-соответствий → личный token 30 минут → выбранные snapshot IDs + expected_revision → новые независимые снимки → штатный editor.save. Старые снимки/медиа/названия сохранены, остальные поля ячеек не меняются. `ApplyIllustrationsDialog.vue` выдаёт updated(Practice), редактор принимает его через acceptSaved с одним шагом undo. Дополнительные маршруты принадлежат Practices: `illustration-routes.php`.

Техническая зависимость — PHP GD, уже используемый обработкой картинок. Дополнительные npm 3D библиотеки не устанавливались. Модель/контент авторские, сторонних 3D файлов нет.
