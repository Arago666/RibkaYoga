# Медитация и приватное аудио

Подключение: зарегистрировать `App\Modules\Meditation\MeditationServiceProvider` в `bootstrap/providers.php`. Provider сам добавляет аутентифицированные `/meditation` и `/api/meditation/*`. Vue-экран: `meditation/Index`. Миграция `2026_10_22_000021_meditation_audio.php` аддитивна, существующие image assets не меняются.

Media расширен независимым `Media\PublicApi\AudioStore`. Изображения по-прежнему используют прежний `AssetStore` со строгими width/height. Аудио имеет свои таблицы, owner и workspace, приватный путь, SHA-256, кодек, длительность и ревизию. `get()` допускает только свои активные записи; `get($id, true)` — также свой архив. `stream()` авторизует владельца и возвращает локальный путь только внутреннему вызывающему коду. Нельзя публиковать этот путь или придавать аудио доступ через публичную практику.

## API

- `GET /api/meditation/settings`, `PUT` с `expected_revision` и `settings`.
- `POST /api/meditation/sessions` с UUID `id` запуска и `settings`; повтор того же UUID/настроек возвращает ту же сессию.
- `GET /api/meditation/active`, `GET /api/meditation/sessions/{id}`.
- `POST /api/meditation/sessions/{id}` с `expected_revision`, `action`: `heartbeat`, `pause`, `resume`, `complete`, `interrupt`.
- `GET /api/meditation/history`, `GET /api/meditation/export`: `timezone`, `period=1|7|30|180|all`, для истории `page`.
- `GET /api/audio?archived=0|1`, `POST /api/audio` multipart `audio`, `title`.
- `PATCH /api/audio/{id}` с `expected_revision`, необязательными `title`, `archived`.
- `GET /media/audio/{id}` — приватная потоковая выдача с Range через Symfony BinaryFileResponse.

Личные настройки и история принадлежат паре workspace/owner. Время хранится в UTC, календарь/периоды считаются в выбранной IANA зоне. Сессия хранит снимок настроек; изменение сохранённых предпочтений не переписывает историю. Аудио из архива остаётся доступно владельцу для существующей истории, но не предлагается для нового запуска.

Сервер подтверждает активное время короткой 30-секундной арендой, браузер обновляет её раз в 10 секунд. По истечении аренды сессия останавливает начисление, требует явного resume. Паузы не прибавляют время, повторное завершение не прибавляет время/запись. Браузер ставит таймер и звук на паузу при скрытии страницы, offline и pagehide. Сервер не утверждает, что измерил реальное дыхание/медитацию: это время управляемой пользователем сессии.

## Зависимости размещения

Нужны реально установленные `ffprobe` и `ffmpeg` для проверки контейнера/кодека, длительности и полного декодирования до сохранения. Внешние URL и сетевые протоколы отключены у декодера; ни shell interpolation, ни загрузка полного файла в PHP память не используются.

Настройки окружения: `AUDIO_MAX_BYTES=104857600`, `AUDIO_MAX_SECONDS=7200`, `AUDIO_LIBRARY_MAX_BYTES=1073741824`, `AUDIO_FFPROBE_BINARY`, `AUDIO_FFMPEG_BINARY`, `AUDIO_DECODE_TIMEOUT=180`. Настройки находятся в `Media/audio.php` под ключом `ribka_audio`; проверь config cache при изменении.

Для лимита 100 МБ согласовать PHP `upload_max_filesize`/`post_max_size`, Nginx `client_max_body_size` и timeout декодирования/запроса. Файл хранится только после полного успешного декодирования; некорректное аудио не проходит как картинка. Суммарная квота включает архив и защищена Media-owned блокировкой от параллельных загрузок.

Все готовые фоновые звуки и сигналы являются настоящим авторским процедурным синтезом Web Audio. Происхождение/параметры описаны в `resources/js/modules/meditation/soundManifest.ts`. Лес, дождь и волны честно названы синтезом, записей природы/конкурентов нет. У синтезированных петель сглажен стык. Микшер ограничивает уровни и имеет компрессор; выключение плавное. Одиночный тон не выдаётся за бинауральный.
