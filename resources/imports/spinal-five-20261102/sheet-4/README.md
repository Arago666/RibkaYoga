# 4 С/М — Дуга позвоночника. Стена, йога-блоки, носки

Оригинал владельца: `source.jpg`, размер 1155 × 1000. Из листа вырезано 71 вхождений фигур, без генерации и перерисовки. Каждое вхождение имеет собственный ключ и PNG512 ×512 с белыми полями. Пропорции сохранены; качество ограничено исходными маленькими рисунками.

`crops.json` хранит исходные координаты, порядок, группы, переходы, обозначения S/★, текстовые элементы и подчёркивания. Лишние номера, межклеточные стрелки, скобки и отдельные буквы вынесены из изображений. Прямоугольники исключённых из вырезки соседних пометок записаны явно. Зелёные указания движения внутри фигур и реквизит сохранены.

Неоднозначные фигуры получили описательное название и `needs_review: true`; санскритское соответствие не выдумывалось. Результат не является распознаванием поз или подтверждённой преподавателем классификацией. Содержание информационных разделов не создаётся этим скриптом.

`contact-sheet-1.jpg` и `contact-sheet-2.jpg` просмотрены целиком. Воспроизведение всех трёх листов: запустить `../sheet-3/extract_all.py` Python с Pillow. У скрипта настроен путь к оригинальным файлам владельца.
