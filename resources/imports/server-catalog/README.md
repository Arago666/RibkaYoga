# Рисунки из серверного каталога

Рецепты вручную повторяют изображения действующего каталога RibkaYoga и старые
версии изображений из сохранённых листов. Ключи — UUID исходной карточки, для
исторических версий — UUID неизменяемого изображения. Имена карточек не служат
шаблонами для распознавания поз: геометрия сверяется с буквальным рисунком.

- `recipes-manual-a.json`, `recipes-manual-b.json`: 33 карточки, отсутствовавшие
  в первоначальном локальном каталоге, включая обозначение «10 Т.Ш.».
- `recipes-shared-a.json`, `recipes-shared-b.json`: 28 исправленных серверных
  версий общих карточек; остальные 43 используют совместимую геометрию из
  `../catalog-redraw/recipes.json`.
- `recipes-historical.json`: восемь прежних изображений из сохранённых листов.
  Их нельзя заменять текущей позой карточки без изменения смысла занятия.

Рендер выполняет `scripts/render-drawing-pack.mjs` через `drawingGeometry.ts` —
тот же код, который использует редактор. Результат — PNG 1024 × 1024 и исходник
`ribka-drawing` v1 из линий, кривых и окружностей. Текстовая отметка не получает
выдуманную голову. Ни генерация изображений ИИ, ни растровая заглушка не используются.

Оригинальные изображения, выгрузки базы, учётные данные и отчёты переноса находятся
в закрытой локальной папке `.runtime/server-sync` и резервной копии сервера;
они не входят в Git. Перенос сохраняет UUID документов, структуру ячеек, архивные
состояния и прежние снимки. Красивые изображения размещаются через новые снимки,
с сохранением исходных названий поз и первоначальных файлов.
