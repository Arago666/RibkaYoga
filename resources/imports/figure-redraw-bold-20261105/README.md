# Уточнённые рисунки асан

153 векторных рисунка согласованы владельцем для замены прежних изображений 5 ноября 2026 года. Контур — 8,5 единиц в системе координат исходного PNG 512 × 512. Размеры и положения голов, рук и ног сверены с оригиналами; совпадающие конечности могут иметь общую видимую проекцию.

`manifest.json` связывает каждый SVG с канонической карточкой и исходной позицией листа. `poses.json` сохраняет редактируемую геометрию. `viewBox` у каждого SVG соответствует рамке оригинала, одинаковой для сравнения «было / стало».

Для рабочего каталога SVG отрисованы в PNG 1024 × 1024. Замена выполняется отдельной операцией с резервной копией базы, файлов и кода; старые media assets сохраняются. Не изменять содержимое старых файлов на месте. Предыдущие листы, нарезки и начальный набор остаются историческими источниками; обычный `db:seed` не является способом повторной публикации рисунков.

Реалистичные варианты людей создаются встроенным инструментом imagegen по каждой отдельной позе. Они хранятся в приватном `storage/app/private/catalog-comparisons/bold-20261105/realistic`, доступны только на странице `/figure-comparison` своего пространства и не добавляются в media assets каталога, практик, печати или рисовалки. Полные промпты и происхождение файлов сохраняются с пакетом публикации.
