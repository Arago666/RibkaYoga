# Перерисованный исходный каталог

14 октября 2026 года 71 асана из исходного листа владельца перерисована в едином стиле: чёрные линии на белом фоне, одинаковая толщина штриха, сохранение пропорций и свободные поля. Две служебные карточки проверки рисовалки не входили в этот пакет.

`inventory.json` — состояние локального каталога перед заменой изображений. `recipes.json` — вручную подготовленные координаты головы, отдельных отрезков и кривых для каждой карточки по её прежнему `import_key`. Названия, другие названия, категории и идентификаторы прежних карточек сохранены. Предварительные названия с пометкой «уточнить» не заменяются догадками.

Рисунки используют собственные элементы редактора `ribka-drawing` версии 1. Это редактируемая геометрия, без ИИ и автоматического распознавания поз. `scripts/render-drawing-pack.mjs` экспортирует исходники и PNG 1024 × 1024 через тот же `drawElement`, который использует редактор Vue. Каждую голову, линию и кривую можно выделить и изменить при повторном открытии карточки.

После замечания владельца все 71 рисунок повторно сверены с исходными пикселями листа. В 65 уточнены силуэты, направление наклонов, сгибы, пропорции и соединения; шесть уже совпадавших схем сохранены. Две чёрные головы перенесены как заполненные круги после проверки исходника. `reference_review` и `variant_note` в рецептах отмечают 16 миниатюр, где короткие перекрывающиеся штрихи хвата или сустава неразличимы. Предположительное название не использовалось как основание для изменения позы.

В локальной библиотеке карточки собраны в подборку «Базовая последовательность — перерисованный каталог». Замена изображения создаёт новый неизменяемый файл; прежние изображения и снимки ранее сохранённых практик остаются доступны. Перед импортом создана приватная резервная копия БД в `.runtime/backups/`.

Инструкции по подготовке и безопасному применению пакетов: [DRAWING_PACK.md](../../../docs/DRAWING_PACK.md). Генерируемые изображения, исходники для импорта и журналы применения находятся в `.runtime/drawing-pack/` и не включаются в Git.
