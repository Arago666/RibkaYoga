# Карточки из исходного листа

71 рисунок вырезан из первого скриншота, предоставленного владельцем проекта. Повторяющиеся рисунки сохранены как отдельные карточки с номером варианта в названии. Второй скриншот с красными пометками не использовался.

Это прямоугольные вырезки оригинальных линий, увеличенные с белыми полями; рисунки не перерисовывались. Номера строк, стрелки и скобки по возможности исключены границами вырезки. Исходная высота фигур около 15–25 пикселей, поэтому PNG остаются мягкими при увеличении.

- `source.png` — неизменённый исходник.
- `assets/` — отдельные PNG.
- `crops.json` — координаты, положение на листе, названия и признак `needs_review`.
- `manifest.json` — данные для `ribka:import-asanas`.
- `contact-sheet.png` — лист для визуальной проверки нарезки.

Названия определены визуально. У 34 неоднозначных фигур в названии стоит «уточнить», а в описании — пояснение. Это предварительные подписи, а не подтверждённая преподавателем расшифровка. Стандартные названия сопоставлялись со [справочником асан Yoga Journal](https://www.yogajournal.com/pose-finder/pose-finder). Точное соответствие миниатюр остаётся визуальной интерпретацией. Любое название и изображение можно изменить в библиотеке; старые практики сохранят свои снимки.

Повторяемая нарезка: `python scripts/extract-reference-cards.py /path/to/original.png` (нужен Pillow, исходник 588 × 1280). Импорт и его параметры описаны в `docs/IMPORT_ASANAS.md` в корне проекта. Повторный импорт пропускает существующие записи и не перезаписывает исправленные названия.
